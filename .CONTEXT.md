## Hot Paths

```
global hotkey → show/hide window → password prompt (first show) → decrypt latest YYYY-MM-DD.txt (first non-blank line only, as the password check)
Enter → encrypt text (random salt+IV) → append as a new line to today's file → clear box
view mode → decrypt every line of the selected day's file
```

---

## Integration Points

None external. Reads/writes `appsettings.json` and `<NotesDirectory>/YYYY-MM-DD.txt` under the exe directory.

---

## Schema

One file per day, `YYYY-MM-DD.txt`, one Base64 block per line: `[salt 32B][iv 16B][ciphertext]`. Key = PBKDF2(password, salt, 100,000 iters, SHA-256) → 256-bit AES. Each line is independently decryptable. `appsettings.json`: `Hotkey{Modifiers,Key}`, `InsertDateKey`, `NotesDirectory`, `Window{Width,Height,RetainWindowSize}`.

---

## Gotchas

- **No password recovery** — wrong/forgotten password means unreadable notes by design.
- Startup password check decrypts only the **first non-blank line** of the newest file; a file whose first line was written under a different password will fail the check.
- Hotkey default in code (`OemMinus`) differs from `appsettings.example.json` (`NumPadSubtract`).
- Windows-only (`UseWindowsForms`, `RegisterHotKey`); `dotnet test` and builds can't run on the Linux dev workstation — recent `SealedJournal.cs` changes (2026-10-21, timestamp deferral + startup check) are **unbuilt/untested**.
- Remote default branch is `main` (was `master`; tags `v1.0.0`/`v2.0.0` point at the first commit).
